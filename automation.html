framelet://capture

URL 自动化

打开一个 framelet:// 链接就能发起截图。可以从「快捷指令」、终端、Raycast 或 Alfred 打开，也可以写进脚本。设置 › 关于 里有一条可以直接复制的示例。

格式

framelet://capture?mode=<方式>&delay=<秒>&preset=<名称>

三个参数都可以省略，顺序不限。不写 mode 时按 region 处理，所以 framelet://capture 本身就是一次区域截图。

参数取值省略时
mode下表 9 种之一region
delay0 到 60 的整数秒使用 设置 › 截图 中的延时
preset应用规则或旧版场景的名称按前台应用匹配应用规则

链接里的参数只对这一次截图生效，不会改动你的设置。

mode：截图方式

取值区分大小写，必须是下面的小写英文。

mode菜单中的名称行为
region区域截图冻结屏幕后框选。选区中按空格可以切换到窗口模式。
window窗口截图打开窗口选择列表，可按应用或窗口名搜索，↑↓ 选择，↩ 截取。延时在选好窗口之后才开始。
screen全屏截图截取鼠标所在的那块屏幕。
all所有屏幕每块显示器一张。最后一张按「截图后」设置处理，其余进入快速访问。
repeat重复选区不显示选区层，直接截取上一次的区域。还没有上次选区时提示「还没有上次选区。请先完成一次区域截图。」
multi多区域截图选区层中 Tab 添加一块，↩ 完成。最后一块按「截图后」设置处理，其余进入快速访问。
scroll滚动长截图（实验性）框选后出现采集面板，可以逐帧截取，或「自动滚动」（需要辅助功能权限）。完成后自动检测重叠，拼成一张长图。
burst连拍按约 500 毫秒的间隔采集 5 帧，帧数和间隔不能调整。每一帧分别保存，并进入快速访问。
text识别文字框选一块区域，识别出的文字和二维码内容直接写入剪贴板。这张截图不保存到历史，也不打开标注层；什么都没识别到时显示失败提示。

delay：延时

0 到 60 的整数，单位是秒，只能写数字：3 可以，3.5、-1、61、3s 都会被拒绝。delay=0 表示这一次不延时，即使设置里开了延时。

倒计时显示在鼠标所在屏幕的菜单栏下方，可以点「取消」，倒计时本身不会被截进去。设置界面只提供 关 / 3 / 5 / 10 秒几个档位，链接可以用 0–60 之间的任意整数。

preset：应用规则或旧版场景

指定这一次截图使用哪套输出设置（截图后动作、格式、倍率、保存位置和标注颜色），而不是按前台应用自动匹配。名称按以下顺序查找：

  1. 应用规则（设置 › 应用规则）。规则的名称是添加规则时记下的应用名，例如 Safari；没有记下应用名时是它的 Bundle ID。
  2. 旧版场景。0.4.0 之前的场景预设在升级时迁移：绑定了应用的场景变成应用规则，其余场景不再显示在设置中，但仍可以按原来的名称在这里使用。

名称必须完全一致，区分大小写，前后的空白会被忽略。找不到时提示「找不到场景：名称」，不会截图。

名称里有空格、中文或 & 等符号时，要先做 URL 编码。空格写成 %20，不能写成 +：

framelet://capture?mode=region&preset=Google%20Chrome

校验

Framelet 先检查整个链接，有任何问题就不截图，并显示一条不打断操作的错误提示：

情况提示
不是 framelet://capture，或带了路径、端口、用户名、# 片段无效的 Framelet 动作链接。使用 framelet://capture?mode=region。
未知参数（参数名区分大小写，Mode 也算未知）未知的动作参数：名称。
同一个参数出现两次动作参数不能重复：名称。
参数没有值、值为空或只有空白，例如 delay=动作参数不能为空：名称。
mode 不在上表中未知的截图方式：值。可用 region、window、screen、all、repeat、multi、scroll、burst、text。
delay 不是 0–60 的整数截图延时必须是 0 到 60 的整数秒。
preset 找不到找不到场景：名称

示例

终端

# 3 秒后区域截图
open "framelet://capture?mode=region&delay=3"

# 打开窗口选择列表
open "framelet://capture?mode=window"

# 截取鼠标所在屏幕，并使用 Safari 的应用规则
open "framelet://capture?mode=screen&preset=Safari"

# 识别文字：框选后文字进入剪贴板
open "framelet://capture?mode=text"

链接里有 &，记得给整个链接加引号。

「快捷指令」

  1. 在「快捷指令」App 中新建一个快捷指令。
  2. 添加「打开 URL」操作，把链接填进去，例如 framelet://capture?mode=region&delay=3。
  3. 在快捷指令的详细信息里可以给它分配键盘快捷键，或把它固定到菜单栏。

Raycast、Alfred 等启动器里，用它们「打开链接」的方式打开同样的 URL 即可。

命令行参数 --capture

Framelet 的可执行文件接受 --capture <mode>：

/Applications/Framelet.app/Contents/MacOS/Framelet --capture region

它等同于打开 framelet://capture?mode=region：这个进程把链接交给系统后立即退出，由正在运行（或被系统启动）的 Framelet 完成截图，所以校验规则和错误提示与链接相同。--capture 只能指定 mode，需要延时或应用规则时请直接使用链接。路径按你实际安装的位置修改。

运行条件

  • 仍然需要屏幕录制权限。链接不会绕过 macOS 的授权。还没授权时 Framelet 显示欢迎页；欢迎页期间到达的链接会排队，如果关闭欢迎页时仍未授权，这些链接被丢弃，并提示「截图需要屏幕录制权限」。
  • Framelet 没有运行时，系统会先启动它；启动完成前到达的链接会排队执行。
  • 已有截图正在进行时，新的链接不执行，提示「请完成或取消当前捕获」。
  • 同一台 Mac 上只有一份 Framelet 能接收 framelet:// 链接。开发构建（Framelet Dev）不注册这个链接。
