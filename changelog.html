更新日志

每个版本中你能感受到的变化。安装包在 GitHub Releases。

0.4.0 未发布

一次整体重新设计：新的标注工具条、选区层、快速访问、历史、贴图和设置，并加入英文界面。

升级须知

  • 快捷键会迁移一次。仍是旧默认值的快捷键改为新默认值：区域截图 ⌃⇧2 → ⌃⇧4，窗口截图 ⌃⇧4 → ⌃⇧W。全屏 ⌃⇧3、重复选区 ⌃⇧5、贴图 ⌃⇧P 不变；新增识别文字 ⌃⇧O 和历史 ⌃⇧H。你改过的快捷键保持不变；新默认值和它冲突时，原有操作保留旧组合，识别文字和历史改用同一按键加 ⌥。
  • 场景预设改为应用规则。默认场景并入通用和输出设置；绑定了应用的场景变成该应用的规则；其余场景不再显示，仍可通过 framelet://capture?preset=名称 使用。
  • 导出倍率改为「保持原始 / 缩小到 1x」。原来的 50% 改为缩小到 1x（Retina 截图结果相同），200% 改为保持原始。
  • 不能降级。0.4.0 保存过的记录，0.3.x 无法读取，会把它当作损坏文件隔离。升级后不要再运行 0.3.x。

新增

  • 英文界面。设置 › 通用 › 语言可选跟随系统、中文或 English，重新打开 Framelet 后生效。
  • 识别文字截图：⌃⇧O 或菜单「识别文字」，框选后文字和二维码内容直接进入剪贴板；没有识别到内容时提示。这类截图不保存到历史。
  • 快速访问：截图后可以停在鼠标所在屏的左下角，最多 5 张。悬停可标注、保存、贴图、复制或关闭，可以把图片拖到其他应用；8 秒后自动消失，指针停在上面时不消失。多区域、所有屏幕、连拍中没有进入标注的其余结果也放在这里。
  • 历史窗口（⌃⇧H 或菜单「历史…」）：按天分组的缩略图，可按标题和图中文字搜索；可重新标注、复制、在访达中显示、移到废纸篓，也可以把缩略图拖到其他应用。菜单栏新增「最近截图」，列出最近 8 张。
  • 美化背景：标注工具条上的弹层，可选背景色、留白、圆角和阴影。
  • 选区层：按空格在区域和窗口之间切换；放大镜显示像素坐标和色值；实时显示像素尺寸；松手前也可以用方向键微调。
  • 测距标注：可保存、可再次编辑，显示两端刻度和像素长度。
  • 标注时 ⌘P 贴图、⇧⌘O 识别文字。
  • URL 自动化新增 framelet://capture?mode=text，发起识别文字截图，见 URL 自动化。
  • 选中标注对象时旁边出现浮动菜单：样式、编辑文字、置顶（⇧⌘]）、复制一份（⌘D）、删除。
  • 选中的标注可以从四角和四边调整大小，箭头、线条和测距拖动两端；指针显示对应的调整光标，⇧ 保持比例或让端点按 45° 吸附，⌥ + 方向键不用鼠标调整大小。
  • 快捷键可以清除：录制时按 ⌫，显示为「未设置」，对应操作仍可从菜单使用。
  • 贴图：鼠标穿透、锁定位置、右键菜单（复制、保存、重新标注、识别文字、缩放、透明度）；有穿透的贴图时，菜单栏可以一键关闭穿透。
  • VoiceOver：标注画布中的每个对象都能读出类型和内容，可以选中、删除、移动；裁剪选区的尺寸可读；切换工具时播报。
  • 新区域截图进入标注后仍可移动和拖边缩放：从冻结屏幕重新裁取，不拉伸图片，标注保持在桌面上的位置，贴图位置和重复选区随之更新，可以撤销。历史和导入的图片仍用裁剪调整。
  • 绘图工具下，选中的对象（包括刚画好的）可以直接移动、拖控制点缩放；在其他对象上按下会继续画，例如从文字标签拉出箭头，调整其他对象用选择工具（V）。双击文字编辑。
  • 裁剪框在应用前可以移动和缩放。⇧ 移动对象时只沿横向或纵向，⇧ 绘制箭头、直线、测距按 45° 吸附。
  • 一次拖动或一次文字编辑是一个撤销步骤；点选和没有改变结果的操作不占步骤，也不清空重做。Esc 取消正在进行的拖动或文字修改。
  • 更连贯的快捷操作：在标注层空白处双击即复制并退出；⌘S 直接存到保存位置，⇧⌘S 另存为；标注层有右键菜单；标注层里的文字识别直接复制。
  • 选区层：松手时按住 ⌃ 直接复制、跳过标注；拖动时按住空格移动选区；⌃⇧W 直接进入窗口模式。
  • 历史中删除不再确认，立即移到废纸篓，提示消失前可撤销（⌘Z）。
  • 按住 ⌘ 拖动标注层里的截图，直接拖进其他应用；区域模式下单击高亮的窗口即截取；历史窗口按空格快速查看；新的全局快捷键「重新标注上一张」，「最近截图」里按住 ⌥ 直接复制。

变更

  • 整套界面换成新的设计：奶油与石墨配色，随浅色 / 深色外观反转；浮动控件在 macOS 26 上使用 Liquid Glass，在 macOS 15 上使用半透明材质；工具图标和菜单栏图标重新绘制。
  • 标注工具条改为一行：8 个常用工具加最近用过的一个「更多」工具，每个工具有单字母快捷键，数字 1–9 按顺序选择。颜色和粗细放在样式弹层，默认信号橙、中等粗细，粗细按截图倍率换算。屏幕较窄时换成精简版，不再被截断。
  • 标注的新样式：实心箭头加方尾，圆角方块编号，带底板的文字，石墨斜纹遮挡；每个对象带一圈奶油色描边，在深浅背景上都清楚。
  • 选区层不再画贯穿全屏的十字参考线，只保留系统十字光标和放大镜。
  • 快速访问取代预览缩略图；截图后动作中的「缩略图」改名为「快速访问」。
  • 菜单栏菜单重排：区域、全屏、重复选区、识别文字在前；窗口、所有屏幕、多区域、连拍，以及标为「实验性」的滚动长截图和录屏放在「更多截图方式」。「重新打开上一张」移到应用的「文件」菜单。
  • 贴图改为无边框，在截图原位置按 1:1 显示，悬停才出现控制条；滚轮缩放，⌥ + 滚轮调透明度，双击关闭。
  • 设置重做为通用、截图、输出、快捷键、应用规则五类，另有「实验性」和「关于」。快捷键录入后立即生效，冲突或被占用时就地提示并保留原组合。应用规则用应用选择器添加，可为单个应用设置截图后动作、格式、倍率、保存位置和标注颜色；规则只覆盖颜色，粗细仍按工具条的样式档。
  • 欢迎页按三种状态重做：需要权限、拒绝后的设置指引、已授权；↩ 执行主操作。
  • 识别文字面板：文字可以修改，显示字数和行数，⇧⌘C 复制全部，二维码单独列出，可以逐条打开或复制。
  • 识别文字保留表格结构：同一行的各列用制表符分隔，粘贴到表格里会分列；可以在面板里关闭，改为空格分隔。
  • 窗口选择列表：显示应用图标、标题和尺寸，↑↓ 选择，↩ 截取，Esc 取消。
  • 从历史删除的截图移到废纸篓（当前图和原图），清倒废纸篓之前仍可找回。按保留规则自动清理的历史仍直接删除。
  • 拖动标注、保存记录更快：拖动时只重画被拖动的对象；在 500 条记录的图库里，保存一次标注时界面不再停顿。退出时会先把还没写完的图片写到磁盘，写不出时不退出，并提示。

修复

  • 延时截图显示倒计时，可以点击取消。
  • 标注画布上 ⌘C 复制标注图；识别文字面板中 ⇧⌘C 复制全部文字。
  • 「文字」工具图标在中文系统下不再显示成「格式」。
  • 多区域、所有屏幕、连拍的每一张结果都能找到：最后一张按截图后设置展示，其余以叠放缩略图出现。
  • 本地保存失败时不再卡住标注面板和之后的截图：可以重试、另存为图片、放弃更改或取消。
  • 错误改为不打断操作的提示；完成提示可以点「重新标注」「在访达中显示」，鼠标悬停时不会消失。
  • 当前屏幕截图、缩略图、贴图、录屏默认显示器和完成提示统一使用鼠标所在的屏幕。
  • 识别文字或录屏结束得晚时，不会再打断新的截图；过期的识别结果不会在截图中途弹出。
  • 关闭标注面板后释放冻结的桌面画面，长时间使用占用的内存更少。

移除

  • 没有入口的旧界面：图库、Studio 拼图、整页编辑器、模板检查器、参考图管理和系统分享按钮。
  • 「问题与期望」反馈编号。含反馈编号的旧记录仍能打开，反馈内容不再显示。
  • 读取浏览器当前网址的来源功能，以及对应的自动化（AppleEvents）权限请求。
