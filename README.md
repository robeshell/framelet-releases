# Framelet

A native Mac screenshot and annotation tool that lives in the menu bar: press a shortcut, select,
annotate in place, and press Return to copy. Everything stays on your Mac.

- Website: https://robeshell.github.io/framelet-releases/ (中文) · https://robeshell.github.io/framelet-releases/en/ (English)
- Downloads: [Releases](https://github.com/robeshell/framelet-releases/releases) — the first notarized release is coming soon.
- Questions and bug reports: [Issues](https://github.com/robeshell/framelet-releases/issues)

This repository hosts the website (GitHub Pages), the update feed (`appcast.xml`) and the signed,
notarized DMGs. Requires macOS 15 or later.
