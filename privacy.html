隐私说明

这一页说明 Framelet 应用会读取什么、保存在哪里、会不会联网。它描述的是应用的实际行为，不是法律条款。

  • 截图、标注、识别出的文字和历史都保存在你的 Mac 上，不会上传。
  • 不需要账户，没有统计，不收集使用数据。
  • 唯一的网络请求是检查更新：从 GitHub 读取更新列表。
  • 崩溃和卡顿报告只留在本机，不会自动发送。

数据存在哪里

Framelet 把所有内容放在你的用户目录里：

内容位置
截图、可编辑的标注记录、识别出的文字（用于历史搜索）~/Library/Application Support/Framelet/Library
录屏（实验性）~/Library/Application Support/Framelet/Recordings
崩溃和卡顿报告~/Library/Application Support/Framelet/Diagnostics
自动保存的图片（可在设置中修改）~/Pictures/Framelet
设置macOS 的应用偏好设置

文字识别使用 macOS 自带的 Vision 框架，在本机完成。Framelet 没有内置 AI 服务，也没有云端存储。

复制时，图片或文字写入系统剪贴板，和其他应用的复制一样。

遮挡标注在复制和保存时烧入图片，导出的图里看不到原文；但本机的截图库仍保留未遮挡的原始截图，以便你重新编辑。备份或分享截图库文件夹时请注意这一点。

网络

Framelet 没有账户，没有统计，也不包含第三方 SDK，只有用于更新的 Sparkle 例外。

唯一的网络请求是检查更新。是否自动检查由你决定：Sparkle 会先问你一次，之后可以在 设置 › 关于 中更改，也可以只在需要时手动「检查更新…」。它从 GitHub 读取更新列表（appcast）：

https://robeshell.github.io/framelet-releases/appcast.xml

Sparkle 的系统信息收集已关闭，所以请求里没有硬件或系统配置信息。和任何 HTTPS 请求一样，GitHub 会看到你的 IP 地址，以及一个包含应用名称和版本号的 User-Agent。GitHub 如何处理这些信息，见 GitHub 的隐私声明。

截图、标注、文字和历史不会出现在这个请求里，也不会出现在任何其他请求里。

识别出二维码时，识别面板可以打开其中的链接。只有你点「打开」时才会交给浏览器处理，Framelet 自己不访问它。

系统权限

每项权限都可以随时在 系统设置 › 隐私与安全性 中撤销。

权限何时使用
屏幕与系统音频录制截图必需。只在你按下截图快捷键或开始一次截图时读取屏幕内容。Framelet 会在启动、欢迎页和设置中检查这项权限是否仍然有效，检查本身不读取屏幕。
麦克风只在你为实验性录屏打开麦克风时请求和使用。
辅助功能只用于实验性滚动长截图的「自动滚动」，在你点它时才请求；不授权也可以手动滚动并截帧。
输入监控只用于实验性录屏的点击提示和快捷键提示。快捷键提示只记录含 ⌘ / ⌃ / ⌥ 的组合与功能键，不记录普通输入。

全局截图快捷键不需要输入监控或辅助功能权限。

诊断信息

macOS 通过 MetricKit 提供的崩溃和卡顿报告只保存在你的 Mac 上，不会自动发送给任何人。

遇到问题时，你可以在 设置 › 关于 中导出一个诊断文件，自己决定要不要发给我们。这个文件不包含截图，也不包含从截图中识别出的文字。

删除数据

  • 在历史窗口中删除的截图（当前图和原图）会移到废纸篓，清倒废纸篓之前都能找回。所在磁盘没有废纸篓时直接删除。
  • 按保留规则清理的历史是永久删除，不经过废纸篓。保留规则默认是 30 天、最多 500 张，在启动时执行；设置 › 输出 中的「清理历史…」会立即按当前规则清理一次。
  • 要删除全部数据：退出 Framelet，删除应用，再删除 ~/Library/Application Support/Framelet 和 ~/Pictures/Framelet 中你不再需要的图片。

本网站

本网站是托管在 GitHub Pages 上的静态页面，不使用 Cookie，没有统计脚本，也不加载外部字体或资源。作为托管方，GitHub 会处理访问日志。

联系

关于隐私的问题，请在 GitHub Issues 提出。
