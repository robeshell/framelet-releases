framelet://capture

URL automation

Opening a framelet:// link starts a capture. Open it from Shortcuts, Terminal, Raycast or Alfred, or from a script. Settings › About has an example you can copy.

Format

framelet://capture?mode=<mode>&delay=<seconds>&preset=<name>

All three parameters are optional and can come in any order. Without mode, the link captures a region, so framelet://capture on its own is an area capture.

ParameterValueWhen omitted
modeOne of the 9 modes belowregion
delayWhole seconds from 0 to 60The delay in Settings › Capture
presetThe name of an App Rule or a legacy presetApp Rules are matched to the frontmost app

Parameters in a link apply to that one capture only; they never change your settings.

mode

Values are case-sensitive and must be written in lowercase, exactly as below.

modeMenu nameWhat happens
regionCapture AreaFreezes the screen for you to select. Press Space during selection to switch to window mode.
windowCapture WindowOpens the window list. Search by app or window name, choose with ↑↓, capture with ↩. The delay starts after you pick the window.
screenCapture Full ScreenCaptures the screen under the pointer.
allCapture All ScreensOne image per display. The last one follows your After Capture setting; the others go to Quick Access.
repeatRepeat Last AreaCaptures the previous area again without showing the selection layer. If there is no previous area yet: “There’s no last area yet. Capture an area first.”
multiCapture Multiple AreasAdd areas with Tab, finish with ↩. The last area follows your After Capture setting; the others go to Quick Access.
scrollScrolling Capture (experimental)After you select an area, a panel lets you capture frame by frame or Scroll Automatically (needs Accessibility). When you finish, overlaps are detected and stitched into one long image.
burstBurstTakes 5 frames about 500 ms apart; the count and interval are fixed. Each frame is saved separately and goes to Quick Access.
textRecognize TextSelect an area; its text and any QR code contents are copied to the clipboard. The capture isn't saved to History and no annotation layer opens. If nothing is recognized, a failure notice appears.

delay

A whole number of seconds from 0 to 60, digits only: 3 works; 3.5, -1, 61 and 3s are rejected. delay=0 means no delay for this capture, even if Settings has one.

The countdown appears below the menu bar on the screen under the pointer; click Cancel to stop it. The countdown itself never ends up in the capture. Settings only offers Off / 3 / 5 / 10 seconds; a link can use any whole number from 0 to 60.

preset

Chooses which output settings (After Capture action, format, scale, save location and annotation color) this capture uses, instead of matching the frontmost app. Names are looked up in this order:

  1. App Rules (Settings › App Rules). A rule's name is the app name recorded when the rule was added, such as Safari; if no app name was recorded, it is the bundle ID.
  2. Legacy presets. Scene presets from before 0.4.0 were migrated on upgrade: presets bound to an app became App Rules, and the rest no longer appear in Settings but still work here by their old name.

The name must match exactly and is case-sensitive; leading and trailing spaces are ignored. If nothing matches, Framelet shows “Couldn't find the preset “name”.” and doesn't capture.

Percent-encode names that contain spaces, non-ASCII characters or symbols such as &. Write a space as %20, not +:

framelet://capture?mode=region&preset=Google%20Chrome

Validation

Framelet checks the whole link first. If anything is wrong it doesn't capture, and shows a notice that doesn't interrupt what you're doing:

ProblemMessage
Not framelet://capture, or has a path, port, user name or # fragmentInvalid Framelet action link. Use framelet://capture?mode=region.
Unknown parameter (names are case-sensitive, so Mode is unknown too)Unknown action parameter: name.
The same parameter twiceAction parameter can't be repeated: name.
A parameter with no value, an empty value or only spaces, e.g. delay=Action parameter can't be empty: name.
mode not in the table aboveUnknown capture mode: value. Use region, window, screen, all, repeat, multi, scroll, burst or text.
delay isn't a whole number from 0 to 60The capture delay must be a whole number of seconds from 0 to 60.
preset not foundCouldn't find the preset “name”.

Examples

Terminal

# Capture an area after 3 seconds
open "framelet://capture?mode=region&delay=3"

# Open the window list
open "framelet://capture?mode=window"

# Capture the screen under the pointer with Safari's App Rule
open "framelet://capture?mode=screen&preset=Safari"

# Recognize Text: select an area, its text goes to the clipboard
open "framelet://capture?mode=text"

Quote the whole link — it contains &.

Shortcuts

  1. Create a new shortcut in the Shortcuts app.
  2. Add the “Open URLs” action and enter the link, for example framelet://capture?mode=region&delay=3.
  3. In the shortcut's details you can give it a keyboard shortcut or pin it in the menu bar.

In Raycast, Alfred and similar launchers, open the same URL with their “open link” option.

Command-line flag --capture

The Framelet executable accepts --capture <mode>:

/Applications/Framelet.app/Contents/MacOS/Framelet --capture region

This is the same as opening framelet://capture?mode=region: the process hands the link to macOS and exits immediately, and the running (or newly launched) Framelet takes the capture, so validation and messages are the same as for links. --capture only sets mode; use a link when you need a delay or a preset. Adjust the path to wherever you installed Framelet.

Requirements

  • Screen Recording permission still applies. Links don't bypass macOS permissions. Without it, Framelet shows its welcome screen; links that arrive while it is open are queued, and if the welcome screen closes without permission they are dropped with “Capturing needs Screen Recording permission”.
  • If Framelet isn't running, macOS launches it first; links that arrive before it has finished starting are queued and then run.
  • While another capture is in progress, a new link doesn't run: “Finish or cancel the current capture”.
  • Only one copy of Framelet on a Mac receives framelet:// links. The development build (Framelet Dev) doesn't register them.
