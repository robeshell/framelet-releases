Privacy policy

What the Framelet app reads, where it keeps things, and whether it goes online. This describes what the app actually does; it is not legal boilerplate.

  • Captures, annotations, recognized text and history are stored on your Mac and never uploaded.
  • No account, no analytics, no usage data collected.
  • The only network request is the update check, which reads the update feed from GitHub.
  • Crash and hang reports stay on your Mac and are never sent automatically.

Where your data lives

Everything Framelet keeps is in your user folder:

WhatWhere
Captures, editable annotation records, recognized text (for History search)~/Library/Application Support/Framelet/Library
Screen recordings (experimental)~/Library/Application Support/Framelet/Recordings
Crash and hang reports~/Library/Application Support/Framelet/Diagnostics
Auto-saved images (changeable in Settings)~/Pictures/Framelet
SettingsThe app's macOS preferences

Text recognition uses Apple's Vision framework and runs on your Mac. Framelet has no built-in AI service and no cloud storage.

Copying puts the image or text on the system clipboard, like copying in any other app.

Redactions are burned into images when you copy or save, so exported images don't contain the covered content. The library on your Mac still keeps the unredacted original so you can edit again — keep that in mind if you back up or share the library folder.

Network

Framelet has no account, no analytics, and no third-party SDKs except Sparkle, which handles updates.

The only network request is the update check. Whether it happens automatically is up to you: Sparkle asks once, you can change it later in Settings › About, or only use Check for Updates… when you want. It fetches the update feed (appcast) from GitHub:

https://robeshell.github.io/framelet-releases/appcast.xml

Sparkle's system profiling is turned off, so no hardware or system profile is sent. As with any HTTPS request, GitHub sees your IP address and a User-Agent containing the app's name and version. GitHub's privacy statement covers how GitHub handles that.

Captures, annotations, text and history are never part of this request, or of any other.

When a QR code is recognized, the text panel can open its link. That happens only when you click Open, and it is handed to your browser; Framelet doesn't fetch it itself.

Permissions

You can revoke any of these at any time in System Settings › Privacy & Security.

PermissionWhen it is used
Screen & System Audio RecordingRequired for capturing. Screen contents are read only when you press a capture shortcut or start a capture. Framelet checks at launch, on the welcome screen and in Settings whether the permission is still granted; the check itself doesn't read the screen.
MicrophoneRequested and used only if you turn on the microphone for experimental screen recording.
AccessibilityUsed only for “Scroll Automatically” in experimental Scrolling Capture, and requested only when you click it. Without it you can still scroll by hand and capture frames.
Input MonitoringUsed only for the click and shortcut overlays in experimental screen recording. The shortcut overlay records only combinations with ⌘ / ⌃ / ⌥ and function keys, never ordinary typing.

Global capture shortcuts need neither Input Monitoring nor Accessibility.

Diagnostics

Crash and hang reports that macOS provides through MetricKit are kept only on your Mac and are never sent automatically.

If something goes wrong, you can export a diagnostics file from Settings › About and decide for yourself whether to send it to us. The file contains no screenshots and no text recognized from screenshots.

Deleting data

  • Captures you delete in History (the current image and the original) go to the Trash and can be recovered until you empty it. On a volume without a Trash they are deleted directly.
  • History cleaned up by the retention rule is deleted permanently, without going through the Trash. The rule defaults to 30 days and at most 500 captures and runs at launch; “Clean Up History…” in Settings › Output applies it immediately.
  • To remove everything: quit Framelet, delete the app, then delete ~/Library/Application Support/Framelet and any images in ~/Pictures/Framelet you no longer want.

This website

This site is a set of static pages hosted on GitHub Pages. It uses no cookies, no analytics scripts, and loads no external fonts or resources. As the host, GitHub processes access logs.
